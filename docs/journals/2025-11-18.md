## 5. Bugs & Fixes

### Bug 1: Module not found error
**Symptom**: Tests failing with "Cannot find module" error  
**Root cause**: package.json had "type": "commonjs" but code used ES module imports  
**Fix**: Changed to "type": "module" in package.json

### Bug 2: Test file couldn't import functions
**Symptom**: Import statements failing in test files  
**Root cause**: Missing `.js` extension in import paths  
**Fix**: Added `.js` extension to all imports (ES module requirement)

   - Even though not strict TDD, writing tests revealed edge cases

3. **CLI Design**
