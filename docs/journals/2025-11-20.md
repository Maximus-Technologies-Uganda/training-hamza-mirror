## 7. What I Learned Today

1. **Validation Design**
   - Validation rules should have clear rationale
   - User-friendly errors include "how to fix" guidance
   - Failing fast prevents confusing errors downstream
   - Contextual error messages reduce support burden

2. **Error Message UX**
   - Show what the user did wrong
   - Explain why it's wrong
   - Suggest correct usage
   - Include examples when helpful
   - Consistent format across all CLIs
