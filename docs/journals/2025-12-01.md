### 1. Review Packet Requirements Analysis

Analyzed mentor requirements for the review packet workflow to bundle frontend artifacts:

#### Required Artifacts
- Coverage summary (≥50% statements, no critical module below 45%)
- Integration test output
- Screenshots of empty/error/loading states
- Link to contract tests

#### Quality Gates to Verify
| Gate | Requirement |
|------|-------------|
| Next.js Build | `next build` and type-check pass with no warnings |

### 2. Workflow Planning

Identified required updates to `.github/workflows/review-packet.yml`:

1. **Add frontend build & type-check steps**
   - Run `npm run type-check` in frontend directory
   - Run `npm run build` with `NEXT_PUBLIC_API_URL` environment variable

2. **Add coverage collection**
   - Run `npm run test:coverage` for frontend
   - Generate coverage summary markdown
   - Check threshold compliance (≥50% statements)

3. **Add integration test capture**
   - Run `npm run test:integration`
   - Capture output to `integration-test-output.txt`

4. **Add Playwright E2E & screenshots**
   - Install Playwright browsers
   - Run E2E tests to capture screenshots
   - Run a11y smoke tests (`--grep @a11y`)

5. **Add contract test verification**
   - Run `npm run test:contract`
   - Capture output for review packet

6. **Generate Frontend Review Packet**
   - Create `FRONTEND_REVIEW_PACKET.md` with all checklists
   - Link to spec.md, plan.md, data-model.md
   - Include coverage summary, test outputs, screenshot references

### 3. Script Requirements

Identified npm scripts needed:

```json
// frontend/package.json
"test:integration": "jest --testPathPattern=tests/integration",
"test:a11y": "jest --testPathPattern=tests/a11y"

// package.json (root)
"test:contract": "vitest run tests/blog/contract"
```
