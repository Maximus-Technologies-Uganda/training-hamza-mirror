## 7. What I Learned Today

1. **Test-Driven Development**
   - Writing tests first helps design better APIs
   - Seeing tests fail first confirms they actually test something
   - RED → GREEN → REFACTOR cycle provides confidence
   - Tests are faster to write when you know the interface

2. **Factory Pattern**
   - `createStopwatch()` returns object with methods
   - Closure provides private state (startTime, isRunning)
   - No need for classes or `new` keyword
   - Clean, functional approach

3. **Time Formatting**
   - Padding with `.padStart()` for consistent MM:SS.mmm format
   - Math for extracting minutes, seconds, milliseconds
   - Important to handle edge cases (0, negative numbers)

4. **State Management**
   - CLI processes don't persist state
   - Would need file/database for true persistence
   - Demo scripts useful for showing stateful sequences
