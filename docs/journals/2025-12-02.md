### 1. Review Packet Workflow Updates

Updated `.github/workflows/review-packet.yml` with comprehensive frontend support:

#### Workflow Triggers
```yaml
on:
  workflow_dispatch:  # Manual trigger
  pull_request:
    branches:
      - main
      - development
  push:

      - 'feat/**'
      - 'fix/**'
      - 'chore/**'

      - 'docs/review-packet-*.md'
```

### 3. Frontend Review Packet Template

Created comprehensive `FRONTEND_REVIEW_PACKET.md` template with:

- **Spec Reference**: Links to spec.md, plan.md, data-model.md
- **Quality Gates Checklist**:
  - Next.js Quality Bars (build, type-check, env vars, URL shareability)
  - Functionality (list posts, create posts, empty/loading/error states)
  - A11y Requirements (labeled controls, focus, aria-live)
  - Coverage Requirements (≥50% statements, ≥45% critical modules)
  - Contract Discipline (API tests pass, spec updates on breaks)
  - Phase 0 Carry-over (Postman fixes merged)
- **Test Results**: Coverage summary, integration/contract/a11y output
- **Screenshots**: References to empty/loading/error/success states
- **Links**: Contract tests, Postman report, coverage report, Playwright report
- **Deploy Documentation**: Vercel SSR / Pages static export
